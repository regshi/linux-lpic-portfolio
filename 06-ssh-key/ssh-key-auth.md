# SSH鍵認証

## 目的

SSHのパスワード認証ではなく、公開鍵認証を使ってログインする方法を確認する。

## SSH鍵の作成

```bash
ssh-keygen -t ed25519
## 作成されるファイル

```text
~/.ssh/id_ed25519      秘密鍵。自分のPCに保管し、GitHubには絶対に載せない。
~/.ssh/id_ed25519.pub  公開鍵。接続先サーバーに登録する。

## 実行結果を残すときの注意

実際の鍵の中身は貼らずに、こう書けばOKです。

```md
`ssh-keygen -t ed25519` を実行し、SSH鍵ペアを作成した。

作成後、`~/.ssh/id_ed25519` と `~/.ssh/id_ed25519.pub` が作成されたことを確認した。

秘密鍵はGitHubに公開しないよう注意する。
