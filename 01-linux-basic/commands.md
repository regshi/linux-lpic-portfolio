# Linux基本コマンド

## pwd

現在いるディレクトリを表示する。

```bash
pwd
```

## ls

ファイルやディレクトリを一覧表示する。

```bash
ls
ls -l
ls -a
```

## cd

ディレクトリを移動する。

```bash
cd /home
cd ..
cd ~
```

## mkdir

ディレクトリを作成する。

```bash
mkdir test
```

## touch

空のファイルを作成する。

```bash
touch memo.txt
```

## cp

ファイルをコピーする。

```bash
cp memo.txt memo_backup.txt
```

## mv

ファイル名を変更、またはファイルを移動する。

```bash
mv memo.txt new_memo.txt
```

## rm

ファイルを削除する。

```bash
rm memo.txt
```

## cat

ファイルの中身を表示する。

```bash
cat memo.txt
```

## history

過去に入力したコマンド履歴を表示する。

```bash
history
```

## 学んだこと

Linuxでは、コマンドを使ってファイルやディレクトリを操作する。  
サーバー管理ではGUIではなくCUIで操作する場面が多いため、基本コマンドを理解することが重要だと学んだ。
