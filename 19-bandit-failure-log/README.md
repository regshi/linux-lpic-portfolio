# Bandit 実行失敗ログ

## 目的

OverTheWire Bandit に挑戦しながら、失敗したコマンド・エラー内容・原因・修正方法を記録する。

成功したコマンドだけではなく、なぜ失敗したのかを残すことで、Linuxコマンド、SSH、パス、権限、シェルの理解につなげる。

---

## 記録ルール

- 成功したコマンドは基本的に残さない
- 失敗したコマンドを残す
- エラーメッセージを残す
- なぜ失敗したかを自分の言葉で書く
- パスワードや秘密情報は残さない

---

## Bandit Level 0：SSH接続

### 失敗したコマンド

```zsh
ssh bandit.labs.overthewire.org
```

### エラー内容

```text
Permission denied
```

### 原因

ユーザー名を指定していなかったため、Mac側のユーザー名でSSH接続しようとしていた。

Banditでは、Level 0 のユーザー名として `bandit0` を指定する必要がある。

### 修正の考え方

SSHでは、接続先だけでなく、以下を正しく指定する必要がある。

```text
ssh -p ポート番号 ユーザー名@接続先
```

### 学んだこと

- SSHでは `ユーザー名@ホスト名` の形で接続する
- `-p` は接続先ポート番号を指定するオプション
- Permission denied は、ユーザー名・パスワード・鍵・権限などが原因で出ることがある
- パスワード入力中は画面に文字が表示されない
