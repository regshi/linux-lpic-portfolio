
# vi エディタ：コマンドモード操作メモ

## viの基本

viには主に2つの状態がある。

- コマンドモード：移動、削除、コピー、保存などを行う
- 入力モード：文字を入力する

viを開いた直後は、基本的にコマンドモードになっている。

入力モードからコマンドモードに戻るには、`Esc` を押す。

---

## モード切り替え

| コマンド | 意味 |
|---|---|
| `i` | カーソル位置の前から入力 |
| `a` | カーソル位置の後ろから入力 |
| `o` | 下に新しい行を作って入力 |
| `O` | 上に新しい行を作って入力 |
| `Esc` | コマンドモードに戻る |

---

## カーソル移動

| コマンド | 意味 |
|---|---|
| `h` | 左へ移動 |
| `j` | 下へ移動 |
| `k` | 上へ移動 |
| `l` | 右へ移動 |
| `w` | 次の単語へ移動 |
| `b` | 前の単語へ移動 |
| `0` | 行の先頭へ移動 |
| `$` | 行の末尾へ移動 |
| `gg` | ファイルの先頭へ移動 |
| `G` | ファイルの末尾へ移動 |
| `数字 + G` | 指定した行へ移動。例：`10G` |

---

## 削除

| コマンド | 意味 |
|---|---|
| `x` | カーソル位置の1文字を削除 |
| `dd` | 現在の1行を削除 |
| `dw` | カーソル位置から単語を削除 |
| `d$` | カーソル位置から行末まで削除 |
| `数字 + dd` | 複数行削除。例：`3dd` |

---

## コピー・貼り付け

| コマンド | 意味 |
|---|---|
| `yy` | 現在の1行をコピー |
| `数字 + yy` | 複数行コピー。例：`3yy` |
| `p` | カーソルの後ろ、または下に貼り付け |
| `P` | カーソルの前、または上に貼り付け |

---

## 取り消し・やり直し

| コマンド | 意味 |
|---|---|
| `u` | 直前の操作を取り消す |
| `Ctrl + r` | 取り消した操作をやり直す |

---

## 検索

| コマンド | 意味 |
|---|---|
| `/文字列` | 下方向に検索 |
| `?文字列` | 上方向に検索 |
| `n` | 次の検索結果へ移動 |
| `N` | 前の検索結果へ移動 |

---

## 置換・変更

| コマンド | 意味 |
|---|---|
| `r文字` | カーソル位置の1文字を置き換える |
| `cw` | 単語を変更する |
| `cc` | 現在の行を変更する |
| `C` | カーソル位置から行末まで変更する |

---

## 保存・終了

| コマンド | 意味 |
|---|---|
| `:w` | 保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 保存せずに強制終了 |
| `:w ファイル名` | 別名で保存 |

---

## 表示設定

| コマンド | 意味 |
|---|---|
| `:set number` | 行番号を表示 |
| `:set nonumber` | 行番号を非表示 |
| `:set paste` | 貼り付け用モードにする |
| `:set nopaste` | 貼り付け用モードを解除する |

---

## よく使う組み合わせ

| 操作 | コマンド |
|---|---|
| 入力開始 | `i` |
| 入力終了 | `Esc` |
| 保存して終了 | `:wq` |
| 保存せず終了 | `:q!` |
| 1行削除 | `dd` |
| 1行コピー | `yy` |
| 貼り付け | `p` |
| 元に戻す | `u` |
| ファイル末尾へ移動 | `G` |
| ファイル先頭へ移動 | `gg` |

---

## 学習メモ

viでは、文字入力をする前に `i` などで入力モードに入る必要がある。

編集が終わったら `Esc` でコマンドモードに戻り、`:wq` で保存して終了する。

LPICでは、viの基本操作として、移動、入力、削除、保存、終了の操作を覚えることが重要だと感じた。
