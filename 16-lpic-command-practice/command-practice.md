# LPICコマンド問題練習

## 目的

LPICのコマンド問題に慣れるため、問題で出てきたLinuxコマンドをUbuntu上で実際に実行し、意味と使い方を整理する。

ハンズオンで学んだ内容を、試験問題で問われる形に結びつけることを目的とする。

## 実行したこと

LPICの問題を解き、分からなかったコマンドや重要だと感じたコマンドをUbuntu上で実行した。

問題文だけでは理解しにくいコマンドも、実際に実行することで、表示結果や使う場面を確認した。

## コマンド一覧

### df

```bash
df -h
```

ディスク容量の使用状況を確認するコマンド。

`-h` オプションを付けることで、容量を人間が読みやすい単位で表示できる。

サーバー監視や障害対応では、ディスク容量が不足していないか確認するために使う。

### free

```bash
free -h
```

メモリ使用量を確認するコマンド。

物理メモリ、空きメモリ、swapの使用状況を確認できる。

サーバーが重いときに、メモリ不足が原因かどうかを確認するために使う。

### ps

```bash
ps aux
```

実行中のプロセスを確認するコマンド。

どのユーザーが、どのプロセスを実行しているかを確認できる。

CPUやメモリを多く使っているプロセスを調べるときに使う。

### systemctl

```bash
systemctl status ssh
systemctl is-active ssh
systemctl is-enabled ssh
```

サービスの状態や自動起動設定を確認するコマンド。

SSHやNginxなどのサービス管理で使用する。

`status` は詳しい状態確認、`is-active` は現在起動中かどうか、`is-enabled` は自動起動設定の確認に使う。

### chmod

```bash
chmod 755 script.sh
ls -l
```

ファイルやディレクトリの権限を変更するコマンド。

`ls -l` と組み合わせることで、権限がどのように変更されたか確認できる。

### chown

```bash
sudo chown user:user file.txt
```

ファイルやディレクトリの所有者・所有グループを変更するコマンド。

サーバー管理では、ファイルの所有者が正しく設定されているか確認することが重要。

### apt

```bash
sudo apt update
sudo apt install nginx
apt show nginx
```

Ubuntuでパッケージを管理するコマンド。

パッケージ情報の更新、インストール、詳細確認に使う。

### ss

```bash
ss -tuln
```

待ち受け中のポートを確認するコマンド。

SSHの22番ポートやNginxの80番ポートを確認する際に使う。

### journalctl

```bash
journalctl -u nginx --no-pager | tail -20
journalctl -u ssh --no-pager | tail -20
```

systemdで管理されているサービスのログを確認するコマンド。

サービスが起動しない場合や、エラー原因を調べるときに使う。

## 学んだこと

LPICのコマンド問題は、暗記だけではなく、実際にLinux上で動かして確認することで理解しやすくなる。

特に、`df`、`free`、`ps`、`systemctl`、`chmod`、`chown`、`apt`、`ss`、`journalctl` は、これまでのハンズオン内容ともつながっている。

問題演習で分からなかったコマンドは、Ubuntu上で実行し、表示結果を確認することで記憶に残りやすくなると感じた。

今後は、Ping-tや問題集で間違えたコマンドをこのファイルに追加し、コマンドの意味・使う場面・実行結果を整理していく。
