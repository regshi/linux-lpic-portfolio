# htopによるサーバー監視

## 目的

Ubuntuサーバーに `htop` をインストールし、CPU使用率、メモリ使用量、プロセスの状態を確認する。

インフラ作業では、サーバーの負荷状況や動作中のプロセスを確認し、異常がないかを把握することが重要。

## 実行したこと

MacのターミナルからUbuntuへSSH接続し、Ubuntu上に `htop` をインストールした。

その後、`htop` を起動して、CPU、メモリ、プロセスの状態を確認した。

## コマンド一覧

### UbuntuへSSH接続

```bash
ssh user@192.168.64.3
```

MacのターミナルからUbuntuへSSH接続した。

### パッケージ情報の更新

```bash
sudo apt update
```

インストール可能なパッケージ情報を更新した。

### htopのインストール

```bash
sudo apt install htop
```

サーバー監視に使う `htop` をインストールした。

### htopの起動

```bash
htop
```

CPU使用率、メモリ使用量、swap、実行中のプロセスを確認した。

### htopの終了

```text
q
```

`q` キーを押して `htop` を終了した。

## htopで確認できること

- CPU使用率
- メモリ使用量
- swap使用量
- 実行中のプロセス
- プロセスID
- コマンド名
- CPUやメモリを多く使っているプロセス

## 学んだこと

`htop` を使うことで、サーバーの負荷状況を視覚的に確認できる。

`uptime` や `free -h` のような単体コマンドでも状態確認はできるが、`htop` を使うとCPU・メモリ・プロセスをまとめて確認できる。

障害対応では、サーバーが重いときに、どのプロセスがCPUやメモリを多く使っているか確認することが重要だと学んだ。
