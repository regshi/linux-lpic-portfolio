# ユーザー管理

## 目的

Linuxでは、ユーザーごとに権限や所属グループを管理する。  
インフラ作業では、利用者ごとにアカウントを作成したり、権限を制御したりするため、ユーザー管理の理解が重要。

## 現在のユーザーを確認する

```bash
whoami
```

現在ログインしているユーザー名を確認できる。

## ユーザーIDやグループを確認する

```bash
id
```

ユーザーID、グループID、所属グループを確認できる。

## 所属グループを確認する

```bash
groups
```

現在のユーザーが所属しているグループを確認できる。

## ユーザーを追加する

```bash
sudo adduser testuser
```

新しいユーザー `testuser` を作成する。

`adduser` は対話形式でユーザーを作成できるため、初心者にも扱いやすい。

## パスワードを変更する

```bash
sudo passwd testuser
```

指定したユーザーのパスワードを変更する。

## ユーザーをsudoグループに追加する

```bash
sudo usermod -aG sudo testuser
```

`testuser` を `sudo` グループに追加する。

`-aG` は、既存のグループを維持したまま新しいグループを追加するために使う。

## ユーザーの切り替え

```bash
su - testuser
```

`testuser` に切り替える。

元のユーザーに戻る場合は以下を実行する。

```bash
exit
```

## ユーザー情報を確認する

```bash
cat /etc/passwd
```

Linuxに登録されているユーザー情報を確認できる。

## グループ情報を確認する

```bash
cat /etc/group
```

Linuxに登録されているグループ情報を確認できる。

## ユーザー管理で注意すること

- 不要なユーザーを作成しない
- パスワードを簡単なものにしない
- sudo権限をむやみに付与しない
- 作業用ユーザーと管理者権限を分ける
- 退職者や不要アカウントは削除・無効化する

## 学んだこと

Linuxでは、ユーザーごとに権限やグループを設定できる。  
インフラ作業では、誰がどの操作をできるかを管理することが重要。

特に `sudo` 権限を持つユーザーはシステム全体に影響する操作ができるため、慎重に管理する必要がある。
