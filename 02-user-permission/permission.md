# 権限管理

## ls -l

ファイルやディレクトリの権限を確認する。

```bash
ls -l
```

## chmod

ファイルやディレクトリの権限を変更する。

```bash
chmod 755 script.sh
chmod 644 memo.txt
```

## chown

ファイルやディレクトリの所有者を変更する。

```bash
sudo chown user:user memo.txt
```

## 学んだこと

Linuxでは、ファイルごとに「誰が読めるか」「誰が書けるか」「誰が実行できるか」が決まっている。  
サーバー管理では、権限設定を間違えるとセキュリティ上の問題につながるため、正しく理解する必要がある。
