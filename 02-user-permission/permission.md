# 権限管理

## ls -l

ファイルやディレクトリの権限を確認する。

```bash
ls -l
```

## chmod

ファイルやディレクトリの権限を変更する。

```bash
chmod 755 script.sh
chmod 644 memo.txt
```

## chown

ファイルやディレクトリの所有者を変更する。

```bash
sudo chown user:user memo.txt
```
## sudo

`sudo` は、一般ユーザーが一時的に管理者権限でコマンドを実行するためのコマンド。

Linuxでは、システムに影響する操作は通常ユーザーでは実行できないことがある。  
そのような場合に `sudo` を付けることで、管理者権限でコマンドを実行できる。

## 使用例

パッケージ情報を更新する。

```bash
sudo apt update
```

SSHサービスを起動する。

```bash
sudo systemctl start ssh
```

システムをシャットダウンする。

```bash
sudo shutdown now
```

## sudoを使う場面

- パッケージのインストール
- サービスの起動・停止
- システム設定ファイルの編集
- ネットワーク設定の変更
- シャットダウンや再起動

## 注意点

`sudo` は強い権限を持つため、実行するコマンドの意味を理解してから使う必要がある。

特に、削除系のコマンドや設定変更コマンドでは注意が必要。

```bash
sudo rm -rf /
```

上記のような危険なコマンドは絶対に実行しない。

## 学んだこと

`sudo` は、一般ユーザーが必要なときだけ管理者権限を使うための仕組み。  
インフラ作業ではよく使うが、システム全体に影響する可能性があるため、慎重に扱う必要がある。
## 学んだこと

Linuxでは、ファイルごとに「誰が読めるか」「誰が書けるか」「誰が実行できるか」が決まっている。  
サーバー管理では、権限設定を間違えるとセキュリティ上の問題につながるため、正しく理解する必要がある。
